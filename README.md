## 🏗️ المعمارية والتقنيات الأساسية:
- **النمط المعماري:** Clean Modular MVC & Services مع فصل كامل لمنطق الأعمال عن القوالب.
- **الخادم واللغة:** PHP 8.2+ (Strict Mode) مع استعلامات PDO المجهزة.
- **قاعدة البيانات:** MySQL 8.x / MariaDB بمحرك **`InnoDB`** حصراً، مع جداول الحركات اللحظية `stock_moves` و `financial_ledger`.
- **النواقص والوظائف المعززة:** باركود الموازين الإلكترونية (للسوبرماركت واللحوم)، تتبع الباتشات وتواريخ الصلاحية، تقرير أعمار الديون (Customer Aging)، وسجل التدقيق والرقابة (Audit Trail).
- **السوق المحلي:** الجنيه المصري (`ج.م` / `EGP`)، ضريبة 14%، وسائل الدفع المصرية (ميزة، إنستاباي، فودافون كاش، كاش، آجل).
- **واجهة المستخدم:** نظام التصميم العصري **`admin-pro`** بهوية براند **«المبرمج»** ودعم الوضع الليلي والنهاري (Dark/Light Mode) واللغة العربية 100% RTL.

```

├── storage/        # النسخ الاحتياطية، السجلات، والمرفوعات

├── pos.php         # شاشة الكاشير السريعة
```
