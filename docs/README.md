### 📑 محاور وثيقة المرجع المحدثة:
1. **هوية وعلامة «المبرمج» ومعايير الدمج البرمجي:** باليت ألوان Cyber-Luxe، مواضع الشعار، والطباعة الحرارية.
2. **تقييم الوضع والرؤية النظيفة:** استئصال الكنترولر القديم المتضخم (4700 سطر) واعتماد معمارية **Clean Modular MVC** مع طبقة الخدمات (Services).
3. **شجرة ملفات المشروع المعتمدة:** هيكل مفصول ومحمي (`app/Services/`, `app/Models/`, `core/`, `views/`, `config/`, `storage/`).
4. **النواقص والوظائف المعززة:** باركود الموازين الإلكترونية (للسوبرماركت واللحوم)، تتبع الباتشات والصلاحيات، تقرير أعمار الديون (Debt Aging)، وسجل التدقيق والرقابة (Audit Trail).
5. **مصفوفة الموديولات الستة وحزمة مصر:** الجنيه المصري (`ج.م`)، ضريبة 14%، وسائل الدفع (ميزة، إنستاباي، محافظ ذكية).
6. **محرك الكاشير فائق السرعة عبر `api.php`:** زمن استجابة 0 ثانية، قارئ باركود الكاميرا، واختصارات F1-F10.
7. **قاعدة البيانات وجداول الحركات اللحظية:** محرك `InnoDB` حصراً، جدول `stock_moves`، وجدول `financial_ledger`.
8. **خطة التنفيذ المنهجية (7 مراحل):** خارطة طريق واضحة لبناء المشروع من البداية دون أي ديون تقنية.
